Madhav E-Commerce Sales Dashboard

Tools: Power BI, Power Query, DAX

Project Overview

An interactive Power BI dashboard developed to analyze e-commerce sales and profitability. The dashboard provides insights into sales, quantity, profit, average order value, customer performance, payment methods, categories, sub-categories, and monthly trends.

Key Features

KPI cards for Sales, Quantity, Profit and AOV
Monthly profit analysis
Sales by state
Payment method analysis
Top customer analysis
Category analysis
Sub-category profitability
Quarter and State filters
Interactive Power BI visualizations
